# Frozen SETU edition schema

These files are unchanged copies of the SETU edition's data schema at
`kenmccarthy/setu-module-review@8acfcc8093e63834058c8d69366f8f23beefaff5` (the commit this edition
was adapted from). They are used only by `tests/compat.test.ts`, which checks that files exported
by this edition can still be read by that version of the SETU edition, and which fields the SETU
edition drops.

Do not edit them. To compare against a newer SETU edition, copy in its files and update the
commit above.
